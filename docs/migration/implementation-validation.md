## 已覆盖的行为

| 范围 | 实际断言 |
| --- | --- |
| 租户隔离 | 伪造租户/组织上下文、修改其他租户组织/角色、跨租户关联组织均被拒绝；没有部分新建账号 |
| 账号与成员 | 删除某租户成员不改共享账号、密码或其他租户成员关系；下次登录避开已停用默认成员；租户管理员不能重置其他共享账号密码或操作全局账号状态 |
| 最后管理员 | 禁用、移除成员、移除管理员角色会保留至少一名有效管理员；并发移除两名管理员仅一项成功，另一项返回冲突 |
| 授权 | 有效应用开通与角色资源取交集；撤销开通、停用资源/角色立即生效；自有范围与全租户范围按并集合并；跨应用资源不可混授，包括模拟异常导入记录 |
| 事务 | 批量开通中途失败、重复角色资源、非法 API 绑定、失败开户、失败应用升级均回滚此前 SQL 写入和审计记录 |
| 开户 | 新账号、组织、岗位、成员、角色与授权原子创建；重复审核不新增这些记录 |
| 失效 | 租户/应用开通过期被拒绝；修改密码后旧会话在各租户均失效；撤销使用开通记录 ID 而非租户 ID，并清理默认应用 |
| 资源/API | 保存资源精确替换 API 关联；解除后接口仍在契约目录内但拒绝访问；重新关联恢复访问；未注册 API 不可通过管理请求新增 |
| 组织 | 仍有关联成员或子节点的组织、岗位不能直接停用/移动/删除；登录和授权重新校验默认组织，保留有效的显式组织选择 |
| 查询 | 操作目录搜索、资源搜索、合法排序与非法排序拒绝；角色已关联成员过滤在分页前执行并保持正确总数；平台指定租户时资源选择受该租户开通范围约束 |
| 分页 | 1,002 条有效权限不被查询页大小 1,000 截断，末尾权限仍可鉴权；管理查询返回页内容及独立的真实总数 |
| 应用扩展 | 注册幂等、同版本内容变更拒绝、升级保留既有资源 ID/授权及停用状态、新资源不会自动开通、未开通租户不能访问新应用；UI 创建应用为停用草稿，未注册或缺少服务/路由/首页配置时禁止启用 |
| 请求容错 | typed request 为 nil 返回 400，缺失认证上下文返回 401；负上下文 ID 拒绝；上述路径无 panic |
| 删除/字典 | 仅无引用的未开通租户可直接删除；已开通或仍有数据的租户拒绝删除；地区父节点和叶节点的 `has_children` 正确 |

## 当前安全语义与限制

1. 基础管理的成员、组织、角色和审计列表属于**租户管理面**，当前按租户隔离，不按个人/部门进一步过滤这些管理列表。`CheckAccess` 为后续应用返回 `tenant_id`、`all_within_tenant` 与 `user_ids`；应用必须执行租户条件及相应数据范围，空 ID 列表不表示全量。
2. 基础命令校验语义操作权限。HTTP 网关仍需先按准确的 method/path 调用 `CheckAccess`，防止共享语义操作的多个接口绕过各自资源绑定；本文件的核心测试不替代网关测试。
3. 核心实际授权计算不分页，普通管理查询每页最多 1,000 条。资源树和整量授权编辑的调用方必须遍历所有页或明确拒绝不完整结果，不能丢弃 `total` 后保存整个授权集合。
4. SQL 权限读取无缓存，修改立即从数据库生效。写事务当前先获取平台级数据库行锁，保证本次验证中的并发管理员与多实体写入正确性；尚未做吞吐量/大租户规模压测。
5. `operations.resource_id` 在 SQL 中允许 NULL，领域表示为 0；保留外键，未绑定操作默认拒绝。保存关联集合是整量替换，空集合表示全部解除。
6. 平台跨租户操作的审计目前归属操作者上下文租户，不自动复制到目标租户的审计列表。基础管理员模板角色资源不可通过一般角色编辑修改；新增业务角色可在租户有效开通范围内配置。
7. 重复 bootstrap 不修改已有密码、不提升已有普通账号，也不自动恢复被撤销权限。已存在平台账号但被禁用时重跑 seed 不会恢复它，恢复操作需独立处理；这里未执行灾难恢复演练。
8. 没有使用旧生产库或完整旧 DDL 做历史数据转换验收。地区测试数据只在独立测试库中构造，不代表正式行政区划数据已导入。应用扩展测试验证核心注册和鉴权返回的路由描述，不证明实际独立应用服务网络部署成功。

9. 租户管理员不能通过输入已有全局账号的手机号修改该账号或越权建立成员关系；跨租户已有账号接入当前由平台管理员处理，邀请/接受邀请流程尚未实现。
