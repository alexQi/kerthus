# 内置浏览器人工验收环境

在项目根目录运行 `python3 scripts/visual-acceptance.py`。脚本启动真实 Go
网关、私有内存注册中心中的 RPC、独立 MySQL 随机库、独立 Redis 命名空间、
独立 MinIO 随机桶，以及 `http://127.0.0.1:15174` 上的复用前端。
已有的 `15173` 前端、`18080` 网关和历史数据不受影响。

默认从 `.local/saas.env` 读取本地基础设施配置，只使用其中的 Docker MySQL
测试实例密码、Redis 和 MinIO 连接。显式 `KERTHUS_TEST_MYSQL_DSN` 可以指定
其他有建库权限的测试实例；脚本始终新建随机库，不使用 DSN 中原有的库。
数据库及对象存储凭据不会打印。环境需要本地 Go、Node、前端已安装依赖，
以及 Docker MySQL/Redis/MinIO 服务运行。

脚本生成 `.local/visual-acceptance-logo.png`，用于头像与 Logo 上传。

终端会输出随机 API 地址、临时配置文件路径和 `supervisor_pid`。
使用内置浏览器打开 `15174`，手工交互并查看截图；本脚本不自动操作浏览器。
重启环境后需要刷新页面，浏览器才能取得新的随机 API 地址。

完成后按 Ctrl-C，或对输出的 supervisor PID 发送 `SIGTERM`。
脚本停止自己的 Vite 和 Go 进程，撤销本环境会话，清空并删除自己的随机
MinIO 桶，删除随机数据库及临时配置。勿使用 `SIGKILL`，它会绕过清理。
合成 PNG 保留在 `.local`，方便复现上传验收。
